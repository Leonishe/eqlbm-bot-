# Бот оплаты EQLBM.CLUB

Принимает подписку в USDT (TRC20), сам проверяет перевод в блокчейне по TXID,
ведёт сроки и напоминает о продлении.

## Как это работает для игрока

1. С сайта он попадает по ссылке вида `t.me/EQLBMBOT?start=pay_pro_3` — бот сразу
   знает тариф и срок. Если зашёл без ссылки, выбирает кнопками.
2. Бот показывает сумму и адрес кошелька.
3. Игрок переводит USDT и присылает TXID.
4. Бот находит этот перевод в сети TRON, сверяет получателя, сумму и свежесть,
   активирует подписку и отдаёт инвайт в Discord.
5. За 3, 2 и 1 день до конца — напоминание. После оплаты замолкает.
   В день окончания тебе приходит сообщение, что человека пора убирать с сервера.

## Что защищает от подделки

- **Повторный TXID.** Каждый засчитанный хеш пишется в журнал; второй раз тот же
  не пройдёт ни у кого.
- **Чужой TXID.** Транзакции в блокчейне видны всем, поэтому принимаются только
  переводы не старше `TX_MAX_AGE_HOURS` (по умолчанию 24 часа). Чужой свежий
  платёж теоретически можно перехватить, но он уже привязан к своему счёту —
  первый, кто прислал, и получает.
- **Недобор суммы.** Допуск 2 цента на округления кошельков, всё что ниже —
  бот попросит доплатить.

## Переменные окружения

Задаются в Railway → Variables, в коде ничего не зашито. Образец — в `.env.example`.

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `ADMIN_IDS` | твой Telegram ID (можно несколько через запятую) |
| `USDT_ADDRESS` | кошелёк TRC20, на который принимаешь |
| `DISCORD_INVITE` | ссылка-приглашение, уходит после оплаты |
| `GOOGLE_CREDS_JSON` | json сервисного аккаунта целиком, одной строкой |
| `SHEET_KEY` | id таблицы из её адреса |
| `TRONGRID_KEY` | необязательно, снимает лимиты публичного API |
| `TX_MAX_AGE_HOURS` | срок годности транзакции, по умолчанию 24 |

## Google Sheets

Можно взять ту же таблицу, где лежат регистрации — вкладки создадутся сами:

- **subs** — по строке на игрока: тариф, срок, зафиксированная цена, до какого числа.
- **payments** — журнал платежей и защита от повторного TXID.

Не забудь дать сервисному аккаунту доступ к таблице (кнопка «Поделиться»,
адрес вида `...@...iam.gserviceaccount.com`, права редактора).

## Цены

Живут в `config.py`, в одном месте:

```python
TIERS = {"base": 35 → 50, "pro": 100 → 150, "vip": 500 → 500}
DISCOUNTS = {1: 0, 3: 10, 6: 17, 12: 20}
PRICE_SWITCH_DATE = 9 сентября 2026
```

До 9 сентября счета выставляются по цене первого набора, после — по новой.
**Цена, по которой человек зашёл, записывается в его строку и действует при всех
продлениях** — обещание с сайта выполняется само, без твоего участия.

## Люди из аффилейт-программы

Тот, кто пришёл через регистрацию в руме, получает чат бесплатно — подписки у него нет,
напоминания ему не идут, платить он ничего не должен. Завести такого можно двумя способами.

**Ссылкой (проще).** Команда `/invite` выдаёт одноразовую ссылку вида
`t.me/EQLBMBOT?start=aff_XXXX`. Игрок нажимает — и записан. Telegram ID привязывается
сам, ник знать не нужно.

**По нику заранее.** `/add @ник заметка` создаёт строку до того, как человек написал боту.
Когда он потом запустит бота, я узнаю его по нику и привяжу к этой строке.

Если такой игрок позже решит купить подписку — покупает через бота на общих основаниях,
его строка превращается в обычную платную. Никаких скидок и исключений в коде нет.

## Команды

Игроку: `/start`, `/status`, `/help`
Тебе:
- `/subs` — два списка: платные подписки и аффилейт-доступы
- `/invite` — одноразовая ссылка на бесплатный доступ
- `/add @ник` — завести человека заранее
- `/paid @ник <base|pro|vip> <месяцев> [способ]` — записать оплату, прошедшую мимо бота

## Оплата мимо бота

Игрок может расплатиться переводом внутри рума — PokerOK, CoinPoker и так далее.
Такую оплату записываешь командой:

```
/paid @petrov pro 3 перевод в PokerOK
/paid 123456789 base 1 CoinPoker
```

Подписка ставится на тот же срок, что и при обычной оплате, а в журнал `payments`
попадает строка с пометкой способа — чтобы через полгода было понятно, откуда деньги.
Если игрок ещё не запускал бота, ник запоминается и строка привяжется к нему
при первом `/start`. Если ID уже известен — ему сразу уходит подтверждение и инвайт.

Цена в журнал пишется по прайсу тарифа, а не по фактически полученной сумме:
сколько именно фишек он перевёл в руме, бот знать не может.

## Запуск

```bash
pip install -r requirements.txt
python bot.py
```

На Railway — тип сервиса worker, команда из `Procfile`.

## Старый бот

Этот код заменяет предыдущую версию целиком — ранняя регистрация больше не нужна.
На Railway меняешь содержимое сервиса на этот проект и оставляешь тот же `BOT_TOKEN`,
чтобы ссылки с сайта продолжали работать. Два процесса с одним токеном одновременно
запускать нельзя — старый деплой сначала останови.

## Если всё же объединять с текущим ботом

Файлы самостоятельные: `config.py`, `storage.py`, `tron.py` можно положить рядом
с существующим кодом, а из `bot.py` перенести обработчики и задачу напоминаний в
своё приложение. Одна оговорка: токен должен остаться один, два процесса с одним
токеном одновременно работать не будут.
